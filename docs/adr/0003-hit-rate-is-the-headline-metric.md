# Hit Rate, not Bankroll, is the headline result

Across the 26 most recent 15-minute Rounds, median total volume was 0.98 USDC and the
maximum was 2.95 USDC. At the 1 USD stake this project assumes, a single Paper Trade is
roughly the entire volume of a typical Round. Any real order of that size would move the
price it was filled at, so the Bankroll curve cannot be read as "what this Strategy would
have earned" — the prices it is computed from would not have survived the trade.

What the record *can* answer honestly is narrower and still worth knowing: how often each
Strategy picks the winning Side. So Hit Rate is displayed as the primary figure, with the
Bankroll curve kept as a secondary, explicitly approximate view.

This is a statement about the current state of the market, not a permanent one. If liquidity
grows by an order of magnitude, revisit it.
